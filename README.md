QuiltRAG

* Standalone version of the author's retrieval-augmented generation (RAG) document Q\&A bot, a dependency of the author's other projects.
* Contains a PyQt desktop app that chunks uploaded PDF, DOCX, TXT and MD files, embeds them locally, and stores them in a ChromaDB vector database.
* Script is meant to be run with `python main.py` after setting GEMINI\_API\_KEY (required) and HF\_TOKEN (optional) in .env.
